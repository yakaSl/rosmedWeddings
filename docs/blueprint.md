# **App Name**: LensBloom

## Core Features:

- Hero Section: Featuring a full-screen background image carousel with overlay title and call-to-action (e.g., 'View Gallery').
- Photographer Story: Two-column layout showcasing the photographer's story, vision, and personal touch, accompanied by a professional portrait.
- Portfolio Showcase: Filtered portfolio supporting images and embedded videos with a lightbox for full-size viewing.
- Package Information: Presenting wedding package details in clean pricing cards.
- Contact Form: A simple form to submit messages
- AI Wedding Style Tool: The site can use an AI tool to suggest photography styles based on the user's preferences and wedding theme, enriching the user's planning experience.

## Style Guidelines:

- Primary color: Rich Taupe (#5b4b3f) to evoke sophistication and romance.
- Background color: Warm Cream (#f8f5f0), subtly tinted, for a light and airy feel.
- Accent color: Elegant Beige (#D9C3AA) to complement the primary color and add a touch of elegance.
- Headline font: 'Playfair', serif, for elegant titles and headings; body text: 'PT Sans', sans-serif, for readability.
- Use minimalistic, line-style icons for navigation and key features.
- Clean and spacious layouts with ample white space to create an airy and premium feel.
- Subtle transitions and animations to enhance user experience without being distracting.
